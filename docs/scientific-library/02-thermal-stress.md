# Thermal stress

The hazard BALIZA can document today is satellite sea-surface heat from NOAA CRW v3.1, not in-colony temperature.

CoralTemp is a nighttime foundation temperature calibrated to 0.2 m (SRC-NOAA-METHOD). HotSpot and DHW are derived from it and from the MMM climatology (SRC-SKIRVING-2020).

What is not established in this library: a depth correction, a species tolerance, or a statement that a given number of degree-weeks kills a given percent of a local assemblage. CRW's alert legend uses mortality-risk phrases. Those phrases stay inside the external product.
