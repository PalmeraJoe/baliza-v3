# Degree Heating Weeks

Definition used by CRW v3.1 (SRC-SKIRVING-2020): over the last 84 days, sum HotSpot values that are at least 1 °C, and divide each included value by 7. Unit: °C-weeks.

The 1 °C cutoff is part of that product's definition. It is not adopted as a BALIZA biological constant.

DHW is an external observation. It can later sit in evidence. It does not open an alert by itself. The CRW table that maps DHW bands onto Alert Levels 1–5 is CRW's classification, recorded in `sources/noaa-crw.md`, and is not a `RuleVersion`.
