# 27 — Source capability matrix

Canonical matrix: `docs/scientific-library/source-capability-matrix.md`.

NOAA CRW supplies the thermal hazard grid. Allen Coral Atlas supplies shallow-reef spatial context. EMODnet supplies European and selected-Caribbean environmental context, not global reef heat. MERMAID supplies field ecological observations where a project submitted them and the data policy allows the row (`docs/scientific-library/sources/mermaid.md`). Resort history is a site calibration and validation channel, not a fifth global feature source. A filled cell is not a selected model feature. BALIZA local biological fields are still `NOT_AVAILABLE` in the schema.
